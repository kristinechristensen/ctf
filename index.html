02 / VM SETUP

Set up your Ubuntu VM

These commands are intended for the Ubuntu VM in NETLAB+ or your own Ubuntu environment. Run one block at a time.

Before you begin: Your VM needs working internet/DNS. On the workshop NETLAB+ image the adapter was ens18. If apt update cannot resolve Ubuntu servers, ask the lab administrator before changing network settings.
1 · Test networking
ip -br addr
ip route
ping -c 4 8.8.8.8
resolvectl query us.archive.ubuntu.com
2 · Update and install tools
sudo apt update
sudo apt install -y docker.io git pipx
sudo systemctl enable --now docker
3 · Install Docker Compose
sudo apt install -y docker-compose-v2
sudo docker compose version
If the package is unavailable, see the official Compose plugin instructions.
4 · Verify Docker
sudo docker run hello-world
sudo systemctl status docker
Press q to exit the service status display.

03 / DEPLOY

Launch your CTFd server

Clone the official CTFd project and run its Docker Compose stack. Initial image downloads/builds can take time.

5 · Clone and start CTFd
cd ~
git clone https://github.com/CTFd/CTFd.git
cd CTFd
sudo docker compose up -d
sudo docker compose ps

Open the setup wizard

Visit http://localhost:8000 inside your VM. If needed, try http://localhost with the official Compose configuration.

Create your administrator account, set a competition name, and choose individual users or teams.

Test as a student

Keep your admin login in a normal Firefox window and use Ctrl + Shift + P for a separate private participant session.

Test challenge visibility, file downloads, flag submissions and scoring.

04 / IMPORT

Load the 20-challenge library

Use ctfcli to import challenges with their descriptions, flags, zero-cost hints, solution writeups, and attached files. The CLI version is pinned for reproducibility.

Workshop caution: Test in a fresh CTFd instance. Importing may create duplicate challenges when similar ones already exist. Never share your admin API token or commit the .ctf/ directory.
6 · Install ctfcli
pipx ensurepath
pipx install 'ctfcli==0.1.8'
ctf --help
Open a new terminal if ctf isn't found after pipx ensurepath.
7 · Download a workshop library copy
cd ~
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
Replace placeholders with your published repository URL, or unzip the download above and enter its folder.
8 · Initialize the event
ctf init
Use http://localhost:8000 and an admin API token generated in CTFd. Keep the token private.
9 · Import a single example
ctf challenge add challenges/01-it-ticket-triage
ctf challenge install challenges/01-it-ticket-triage
Verify the challenge and attached file in the CTFd admin panel.
10 · Import the remaining challenges
for dir in challenges/*; do
  ctf challenge add "$dir"
done
ctf challenge install
Use only after validating one import. If your CLI version does not accept a bulk install without a path, install each registered challenge individually.

Prefer manual entry?

Open a challenge’s challenge.yml, copy the description and flag into the CTFd admin UI, then attach its file from dist/. Paste writeup/SOLUTION.md into the Solution tab.

Just want one evidence file?

In CTFd, open an existing challenge and select its Files area to upload a log, CSV, Python, or Rust file. No CLI needed.
