02 / VM SETUP

Set up your Ubuntu VM

These commands are intended for the Ubuntu VM in NETLAB+ or your own Ubuntu environment. Run one block at a time.

Before you begin: Your VM needs working internet/DNS. On the workshop NETLAB+ image the adapter was ens18. If apt update cannot resolve Ubuntu servers, ask the lab administrator before changing network settings.
1 · Test networking
ip -br addr
ip route
ping -c 4 8.8.8.8
resolvectl query us.archive.ubuntu.com
2 · Update and install tools
sudo apt update
sudo apt install -y docker.io git pipx
sudo systemctl enable --now docker
3 · Install Docker Compose
sudo apt install -y docker-compose-v2
sudo docker compose version
If the package is unavailable, see the official Compose plugin instructions.
4 · Verify Docker
sudo docker run hello-world
sudo systemctl status docker
Press q to exit the service status display.

03 / DEPLOY

Launch your CTFd server

Clone the official CTFd project and run its Docker Compose stack. Initial image downloads/builds can take time.

5 · Clone and start CTFd
cd ~
git clone https://github.com/CTFd/CTFd.git
cd CTFd
sudo docker compose up -d
sudo docker compose ps

Open the setup wizard

Visit http://localhost:8000 inside your VM. If needed, try http://localhost with the official Compose configuration.

Create your administrator account, set a competition name, and choose individual users or teams.

Test as a student

Keep your admin login in a normal Firefox window and use Ctrl + Shift + P for a separate private participant session.

Test challenge visibility, file downloads, flag submissions and scoring.

04 / IMPORT

Load the 20-challenge library

Use ctfcli to import challenges with their descriptions, flags, zero-cost hints, solution writeups, and attached files. The CLI version is pinned for reproducibility.

Workshop caution: Test in a fresh CTFd instance. Importing may create duplicate challenges when similar ones already exist. Never share your admin API token or commit the .ctf/ directory.
6 · Install ctfcli
pipx ensurepath
pipx install 'ctfcli==0.1.8'
ctf --help
Open a new terminal if ctf isn't found after pipx ensurepath.
7 · Download a workshop library copy
cd ~
git clone https://github.com/kristinechristensen/ctf.git
cd ctf
This command downloads the workshop repository. Ensure the full `challenges/` and `assets/` directories are uploaded to GitHub first.
8 · Initialize the event
ctf init
Use http://localhost:8000 and an admin API token generated in CTFd. Keep the token private.
9 · Import a single example
ctf challenge add challenges/01-it-ticket-triage
ctf challenge install challenges/01-it-ticket-triage
Verify the challenge and attached file in the CTFd admin panel.
10 · Import the remaining challenges
for dir in challenges/*; do
  ctf challenge add "$dir"
done
ctf challenge install
Use only after validating one import. If your CLI version does not accept a bulk install without a path, install each registered challenge individually.

Prefer manual entry?

Open a challenge’s challenge.yml, copy the description and flag into the CTFd admin UI, then attach its file from dist/. Paste writeup/SOLUTION.md into the Solution tab.

Just want one evidence file?

In CTFd, open an existing challenge and select its Files area to upload a log, CSV, Python, or Rust file. No CLI needed.

05 / CUSTOMIZE YOUR CTFd

Make your CTFd look like Flags to Futures

These changes are made inside CTFd's administrator interface, not in your terminal. Follow the two steps below and use the buttons to copy the ready-made HTML and CSS.

Before editing: Keep your existing CTFd administrator session open. The homepage and theme code in this tutorial match the files in ctfd/. These changes do not alter your challenges, scores, or database.
STEP 1 · HOMEPAGE

Create the welcome page

  1. Open CTFd → Admin Panel → Pages.
  2. Open the homepage with route index, or create that page if needed.
  3. Use the HTML content editor.
  4. Click Copy homepage HTML, paste the content into the editor, then save.
↓ Download HTML

STEP 2 · THEME STYLING

Apply the matching colors and layout

  1. Open CTFd → Admin Panel → Config → Theme.
  2. Locate the Theme Header field.
  3. Click Copy theme CSS, paste the result into Theme Header, and save.
  4. Open the participant homepage in a private Firefox window and refresh.
↓ Download styles

Want to experiment?

Change the colors in the style guide and in the theme header. Save and refresh your test participant window to see the changes. You can always restore the original provided styling using the copy button above.

What should you check?

Test your homepage, navigation, keyboard focus, contrast, challenge board, scoreboard, and mobile screen sizes. This starter theme intentionally scopes most styling to its homepage to reduce conflicts with CTFd's interface.

Note: Your CTFd version or theme may label these settings differently. The copy buttons require GitHub Pages or another web server; opening index.html directly as a local file may block loading the linked HTML.

06 / FROM CHALLENGES TO PATHWAYS

Flags are just the beginning.

Every solved challenge can open a conversation about what learners enjoy, the skills they are developing, and where those interests might lead.

01Try the challengeSolve an authentic, approachable problem.
02Discover what you enjoyNotice curiosity, strategies, and strengths.
03Connect to a roleExplore related IT, cybersecurity, and software careers.
04Explore the pathwayIdentify courses, credentials, and next steps.

Make assessment meaningful

Use attempts, completion patterns, scores, and hints as formative signals. Debrief what students tried and learned rather than treating the leaderboard as proof of mastery.

Design for every learner

Sequence approachable challenges, offer useful hints, test flags and downloadable files, and provide accessible instructions and multiple routes to participation.
