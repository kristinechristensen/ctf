# Packet Trail — Instructor Solution

**Correct flag:** `CTF{5432}`

## How to solve

The SYN targeting 192.0.2.30:5432 receives an RST-ACK, so the database destination port is 5432.

## Learning objective

Correlate TCP ports with connection patterns in simplified packet evidence.
