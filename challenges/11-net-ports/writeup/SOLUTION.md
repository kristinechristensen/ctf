# Which Port Failed? — Instructor Solution

**Correct flag:** `CTF{443}`

## How to solve

TCP port 443 is refused, unlike port 80. A refusal can reflect a service not listening or an active rejection; it does not prove a particular root cause.

## Learning objective

Differentiate reachability from listening application ports.

## Suggested tools

Text editor

Have learners describe the evidence they used, not just submit the flag. The attached artifact is fictional and designed for an isolated classroom exercise.
