# Flags to Futures | Visual Identity Guide

**Tagline:** Build. Play. Teach. Inspire.  
**Academic subtitle:** From Setup to Student Engagement: A Hands-On CTFd Tutorial for Cybersecurity, IT, and Computer Science  
**Brand meaning:** The flag represents a solved challenge; the rising pathway represents curiosity, growth, and career exploration.

## Palette
| Role | Color | Hex |
|---|---|---|
| Background | Midnight | `#0B1429` |
| Panels | Deep Slate | `#152340` |
| Primary | Quest Purple | `#7656D8` |
| Interactive Accent | Cyber Teal | `#5CE0DB` |
| Achievement | Horizon Gold | `#F6C969` |
| Body Text | Cloud White | `#F7FAFF` |
| Secondary Text | Mist Blue | `#BFCEE2` |

Use near-white text on dark backgrounds. Do not use gold or teal for small text over white. Maintain at least 4.5:1 contrast for normal body text and 3:1 for large text/meaningful controls. Test interactive states and focus rings.

## Typography
- Headlines: Space Grotesk (system sans-serif fallback)
- Body: DM Sans (system sans-serif fallback)
- Commands: system monospace

## Voice & visual style
Welcoming, educational, energetic, and credible. Use clear calls to action and avoid jargon without explanation. Prefer clean rounded cards, legible command snippets, gold achievements, teal pathways, and purple flags. Keep all instructions readable on laptops and mobile.

## Assets
- `assets/logo.svg`: scalable primary flag/pathway mark
- `assets/flags-to-futures-hero.svg`: website hero illustration
- `assets/favicon.svg`: browser icon
- `ctfd/homepage.html`: paste into CTFd `index` Page in HTML mode
- `ctfd/theme-header.html`: paste into CTFd Config > Theme > Theme Header

## Inclusive learning narrative
Try the Challenge → Discover What You Enjoy → Connect to a Role → Explore the Pathway. CTF participation should motivate further exploration, not be treated as conclusive evidence of career fit or proficiency.

## Technical note
Do not place CTFd administrator API tokens in this public GitHub repository or within GitHub Pages JavaScript. Instructor solutions are intentionally included for this demonstration collection. Replace flags for graded classroom competitions.
