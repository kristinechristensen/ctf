Typography

Space Grotesk for headings, DM Sans for body text, system monospace for code blocks. Always provide local fallback fonts.

Accessibility

Keep body text on dark panels high contrast, keyboard focus visible, headings structured, and motion reduced when requested. Never communicate status by color alone.
